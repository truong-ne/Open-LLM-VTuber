# Curtain pull sound credits

`curtain-close-v2.ogg` and `curtain-open-v2.ogg` are adaptations of **“21. curtain open close.wav” by btherad2000**, published 5 November 2015 on Freesound.

- Original work: https://freesound.org/people/btherad2000/sounds/328031/
- Public HQ preview used: https://cdn.freesound.org/previews/328/328031_5632195-hq.mp3
- License: **Creative Commons Attribution 4.0 International**, https://creativecommons.org/licenses/by/4.0/
- Changes: selected approximately 1.45–2.48 seconds and 3.45–4.76 seconds, trimmed, filtered low/high frequencies, adjusted tempo to about 0.9/1.2 seconds, added fade in/out and limited peaks, encoded as Ogg Vorbis. Runtime gain is reduced, and further ducked while Mao speaks.
- Adapted for Mao VTuber on 19 October 2026. The original author does not endorse this application. Retain this attribution with redistributed audio.

The curtain illustration `mao-theatre-curtain-v2.png` was generated separately using ChatGPT's built-in image generation tool; it is not part of the Freesound work or a stock Motion Array asset.
